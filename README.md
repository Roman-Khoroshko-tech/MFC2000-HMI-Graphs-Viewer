# MFC2000 HMI Graphs Viewer

Поточна версія: **2.1**. Локальний переглядач CSV-архівів HMI з графіками, датою й часом.

## Запуск

Відкрийте `index.html` або `MFC2000-HMI-Graphs-Viewer.html` у Chrome чи Edge та виберіть CSV. Обидва файли містять ту саму автономну програму. Встановлення, сервер та інтернет для перегляду даних не потрібні.

## Можливості

- Окремі графіки сигналів зі спільним часовим діапазоном.
- Масштабування часу колесом миші та прокрутка перетягуванням.
- Вибір періоду за датою й часом, огляд усього запису та значення під курсором.
- Автомасштаб вертикальної шкали або власні межі «Мін.» / «Макс.» для кожного сигналу.
- Кнопки Y+ / Y− для вертикального масштабу.
- Українська, польська й англійська мови через кнопку UK / PL / EN.
- Світла й темна теми, адаптивне компонування.
- Обробка CSV на пристрої без надсилання даних у мережу.

Дата й час відображаються як у HMI, без перерахунку часового поясу. Після закриття програми CSV потрібно відкрити повторно.

## Файли

- `index.html` — готова автономна програма та головна сторінка для статичного розміщення.
- `MFC2000-HMI-Graphs-Viewer.html` — та сама програма з повною назвою файлу.
- `src/index.html` — вихідна сторінка.
- `src/assets/` — логіка графіків, читання CSV, переклади та стилі програми.
- `src/ui/` — локальні базові стилі й перемикач теми.
- `build.cjs` — створення автономних HTML-файлів із вихідного коду.

## Збирання після змін

Потрібен Node.js. Додаткові пакети встановлювати не потрібно.

```sh
node build.cjs
```

Для подальшої розробки редагуйте `src/` і повторно запускайте збирання. Можна також відкрити `src/index.html` безпосередньо в браузері.
